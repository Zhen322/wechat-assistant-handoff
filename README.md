# 公众号助手 · 完整交接仓库

这是「字里」公众号写作工作台及汽车、车灯行业内容运营资料的交接版本，整理日期为 **2026-11-02**。仓库包含可运行源码、当前已保存业务数据、可直接阅读的全文导出、写作规范、需求文档和历史版本。首次启动会自动恢复 **12 条素材、5 张写法卡、4 篇草稿**；已有数据库不会被覆盖。

本次交接仓库为**公开仓库**：<https://github.com/Zhen322/wechat-assistant-handoff>。其中的业务资料、笔记与历史内容可由任何访问者阅读；密钥和个人登录凭据已排除，采集素材中识别到的私人联系邮箱、手机号以标记替换。所有业务记录保留；本地原件未改变。原开发 README 曾记录 `Zhen322/wechat-writer` 为私有仓库，那是历史开发地址，与本仓库不同。

## 先这样打开

安装 Python 3.11 或更高版本，在仓库根目录运行：

```sh
python3 start.py
```

Windows 可用 `py -3 start.py`。看到启动地址后，浏览器打开 **http://127.0.0.1:8765**。macOS 也可双击根目录 [start.command](start.command)，它会打开浏览器。关闭终端中的 Python 服务时按 Ctrl+C；macOS 脚本后台启动的服务 PID 在 `文案助手/wechat-writer/data/server.pid`。

**首启数据会自动恢复。** `start.py` 将 `handoff-data/` 中的公开脱敏快照恢复到工作台 `data/`，保留已经存在的笔记、配置及正文文件；之后启动直接使用现有数据库。不要一开始直接执行内部 `app.py`，它本身会创建空数据库；若已经这样做过，请先停止服务、保留原数据，按照 [数据恢复说明](handoff-data/README.md) 恢复到新目录。

核心程序只用 Python 标准库，无需 Node 或 Docker。需要导入文本型 PDF 时再安装可选依赖：

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r 文案助手/wechat-writer/requirements.txt
.venv/bin/python start.py
```

Windows 对应 `.venv\Scripts\python.exe`。扫描版 PDF 要先 OCR。端口被占用时，可执行 `python3 start.py --port 8766` 并打开对应地址。

## 接班配置

已有内容可以立即查看。继续生成文章时，在「模型与设置」选择一种可用模型：当前保存的是 Codex 模式（`gpt-6-astra`），需要同事自己的 Codex CLI 登录及模型权限；也可改用 Ollama 或 OpenAI 兼容接口。联网找文章和配图使用 Tavily。配置方法见 [配置模板说明](配置模板/README.md) 与 [详细使用说明](文案助手/wechat-writer/使用说明.md)。

Coze 的两个部署地址、参数合同和历史结果已经保存，**Token 不随仓库交付**。要继续使用云端「选题助手」「文案助手」，需在 Coze 转交项目/工作空间权限、部署与额度管理，再签发接班 Token，在本地设置中填写。**云端工作流源码、云端知识库和账号权限不在本地副本中，尚未完成云端移交。** 本地 B 写作流程及历史资料不依赖这些 Token。
