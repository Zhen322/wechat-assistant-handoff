# 从常州车灯展看2022年车灯最新趋势系列报道一：Mini LED

Original 艾邦团队 艾邦团队 艾邦智造前沿

# 常州车灯展今天刚刚结束，从大的趋势来看，车灯主要发展方向为安全照明、智能助驾、娱乐交互；从新技术的表现形式来看像素化、激光化，ADB、投影灯、小型化，科技感，模块化，集成化，电子化，国产化。由于篇幅有限，接下去我们将以连载形式给大家报道。

像素化，如Mini LED展示明显增多，Mini LED应用场景亦在拓宽，如之前应用在车载显示、车尾灯，如今增加了格栅灯以及logo灯的应用，Mini LED尾灯功能也在拓展，除了之前的显示功能外，增加了显示互动交流的功能等。Mini LED在汽车上的应用拓宽，百花齐放是本次展会亮点之一。

较于传统的LCD液晶显示，Mini LED背光显示具备超广色域、精准控光、超薄及小体积等特点，可为驾乘者带来更高端的视觉及交互体验。由于新能源汽车，传统的进气格栅功能弱化，给整车设计者带来了空间，格栅开始有了互动，显示功能。另外曼德·光电，翌光科技也有展出OLED相关案例。
